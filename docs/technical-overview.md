# 技術說明

## 影片測驗

以 PyQt6 的 QMediaPlayer、QVideoWidget 與 QAudioOutput 播放影片。點擊時讀取播放器位置，將座標與毫秒、秒數輸出為 CSV。程式嘗試取得影片解析度，依等比例顯示區域轉換座標並排除黑邊；若解析度取得失敗，會退回 widget 座標，因此不能保證所有輸出均為原始影片像素座標。

播放器顯示的時間與距離誤差使用固定示範值（5 秒、320 × 240），不是五支影片逐一設定的正式評分結果。原程式允許暫停、拖曳及重複點擊；若用於正式施測，需要另行控制施測流程。

## 批次評分

五支影片共七個危險點，每點最高 20 分，總分最高 140 分。每個危險點獨立比較所有點擊時間與設定的起始時間，以絕對誤差每 0.1 秒遞減，取最高分；超過 2 秒為 0 分。提前與延後點擊採相同規則。

雖然 CSV 含座標，評分程式只使用 time_sec 或 time_ms，沒有位置評分。現行邏輯也沒有額外誤點懲罰。遺失影片 CSV 會被計為零分，不能據此區分未施測與真正零分。浮點數區間邊界尚未做專門處理。
